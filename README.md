# dose-ref 💊

A tiny offline bedside **dosage + antidote quick-reference**. Static page, no
server, no patient data — just a cheatsheet I keep on my phone for shifts.

- **Maintainer:** `bedref`
- **Burner contact:** `bedref.2487@proton.me`

## Usage

Open `index.html`, search a drug, read the dose. Reference data lives in
[`data/doses.md`](data/doses.md).

---

> ⚠️ Clinical reference only — no substitute for judgment. Anything controlled in
> the lab stock is tracked in a **separate sign-out book**, not in this notebook.
