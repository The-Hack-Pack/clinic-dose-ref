# Dose reference table

Adult, general practice. Clinical lookup only.

| Agent                  | Dose / Antidote                          | Notes                          |
|------------------------|------------------------------------------|--------------------------------|
| Acetaminophen          | 650–1000 mg PO q6h (max 3 g/day)         | Antidote: N-acetylcysteine     |
| Adrenaline (anaphylaxis)| 0.3–0.5 mg IM (1:1000), repeat q5–15 min| —                              |
| Amoxicillin            | 500 mg PO q8h                            | Uncomplicated                  |
| Atropine (bradycardia) | 0.5 mg IV q3–5 min (max 3 mg)            | —                              |
| **Cyanide poisoning**  | Hydroxocobalamin 5 g IV over 15 min      | Antidote; sodium thiosulfate adjunct |
| Digoxin                | 0.125–0.25 mg PO daily                   | Narrow therapeutic index       |
| Naloxone               | 0.4–2 mg IV/IM, repeat q2–3 min          | Opioid reversal                |
| Nitroglycerin          | 0.4 mg SL q5 min x3                       | Angina                         |
